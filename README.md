## Overview
This repository implements Monte Carlo methods for estimating the value of π and for evaluating definite integrals. The logic lives in `core/` and is exposed through a lightweight internal HTTP‑style handler in `api/routes.py`.

## Tech Stack
- Python 3.9+
- NumPy for vectorised random sampling

## Theoretical Background
Monte Carlo estimation approximates an integral by random sampling. For π, points are drawn uniformly in the unit square; the ratio of points falling inside the unit quarter‑circle approximates π/4. Increasing the sample size reduces variance as 1/√N.

For a general definite integral \(I = \int_a^b f(x) dx\), the Monte Carlo estimator draws samples \(x_i\) uniformly on \([a,b]\) and computes \(I \approx (b-a) * (1/N) * Σ f(x_i)\). The method is dimension‑agnostic and simple to parallelise, though convergence is slower than deterministic quadrature for smooth low‑dimensional functions.

## Usage
```python
from api.routes import handle_request
payload = {"action": "estimate_pi", "samples": 100000}
response = handle_request(payload)
print(response)
```

## API Reference
| Endpoint | Action | Required Fields | Returns |
|---|---|---|---|
| `/estimate` | `estimate_pi` | `samples` (int) | `{"pi_estimate": float, "error": float}` |
| `/estimate` | `integrate` | `samples` (int), `a` (float), `b` (float), `func` (str) – name of a built‑in function like `sin` | `{"integral": float, "error": float}` |

## Limitations
- Pure‑Python random sampling; not suitable for extremely high‑precision needs.
- Function integration limited to simple NumPy‑compatible callables identified by name.

## Roadmap
- Add support for custom callable objects via import paths.
- Parallel execution using `concurrent.futures`.
- Extend to multi‑dimensional integrals.
